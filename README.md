# Clean Demo Repo

A sample repository demonstrating GitHub repository cleanliness best practices.

This repository was created to showcase how a well-maintained GitHub repository can achieve a high cleanliness score. It includes proper documentation, licensing, issue tracking, branch management, and ignore rules.

The purpose of this project is educational. It demonstrates the five major dimensions used to evaluate repository cleanliness:

1. Branch Hygiene
2. Issue Staleness
3. License Check
4. README Quality
5. .gitignore Coverage

A clean repository is easier to understand, safer to share, and more attractive to contributors.

---

## Installation

Follow these steps to set up the project locally.

### Clone the repository

git clone https://github.com/your-username/clean-demo-repo.git

### Navigate into the project folder

cd clean-demo-repo

### Install dependencies

pip install -r requirements.txt

Run the sample Python application with:

## Repository Cleanliness Dimensions

### Branch Hygiene
Ensures all branches are recently active and unused branches are removed.

### Issue Staleness
Detects open issues that have not been updated for more than 180 days.

### License Check
Confirms that a valid LICENSE file exists.

### README Quality
Measures documentation completeness and usefulness.

### .gitignore Coverage
Checks whether unnecessary and sensitive files are excluded from version control.
